# SMGD Home Assistant-appar

App-förråd för Home Assistant med **SMGD Bridge**, den lokala agenten för SMGD Developer Lab.

Lägg till förrådet i Home Assistant under **Inställningar → Tillägg → Tilläggsbutik → ⋮ → Förråd**:

```
https://github.com/SMGD-MP/smgd-ha-apps
```

Här finns bara appens beskrivning (inställningar, dokumentation, ikon). Själva avbilden hämtas
från `ghcr.io/smgd-mp/smgd-bridge-{arch}`.
